# Práctica de despliegue web con Vercel

## Descripción

Este proyecto fue un ejercicio práctico para aprender a desplegar una página web utilizando **Vercel** y conectarla con un repositorio de GitHub.

El objetivo fue conocer el proceso de publicación de un sitio web y aprender cómo hacer que una página esté disponible en Internet mediante una URL pública.

## ¿Qué es Vercel?

Vercel es una plataforma que permite desplegar proyectos web y publicarlos en Internet. También ofrece integración con GitHub para facilitar la actualización de los sitios cuando se realizan cambios en el código.

### Funcionalidades aprendidas

- **Despliegue web:** publicar una página para que pueda consultarse desde un navegador.
- **Integración con GitHub:** conectar el repositorio del proyecto con Vercel.
- **Entorno de producción:** publicar una versión accesible del sitio.
- **URL pública:** compartir la página mediante un enlace.
- **Control de versiones:** mantener el código fuente en GitHub y facilitar futuras actualizaciones.

## Proceso realizado

1. Crear una página web sencilla.
2. Guardar el código fuente en un repositorio de GitHub.
3. Conectar el repositorio con Vercel.
4. Desplegar el proyecto en el entorno de producción.
5. Verificar que el despliegue se completara correctamente y que la página estuviera disponible mediante su URL pública.

## Herramientas utilizadas

- **Vercel:** plataforma de despliegue y publicación web.
- **GitHub:** almacenamiento y control de versiones del código fuente.
- **HTML:** estructura básica de la página.

## Resultado

Se obtuvo una página web publicada mediante Vercel, accesible desde un navegador y vinculada al proyecto almacenado en GitHub.
